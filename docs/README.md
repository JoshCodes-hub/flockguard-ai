# PoultryGuard — Project Documentation

Defense-prep deliverables generated for the final-year project defense.

| File                                              | Purpose                                                 |
| ------------------------------------------------- | ------------------------------------------------------- |
| [`architecture.md`](./architecture.md)            | System architecture, data flow, the feedback loop      |
| [`demo-script.md`](./demo-script.md)              | 5-minute timed walkthrough for the defense panel       |
| [`screenshot-checklist.md`](./screenshot-checklist.md) | 14-shot capture list for the written report      |

## Tips

- Print `demo-script.md` and keep it next to your laptop during the defense.
- Run the demo seeder from `/demo` immediately before the panel arrives so all
  charts and tables are populated.
- The architecture diagram is ASCII so it renders in any markdown viewer — feel
  free to redraw it in draw.io or Excalidraw for a polished version in the
  written report.
